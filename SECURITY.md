# Security policy

## Scope

This project has no user accounts. Job ownership is scoped to an anonymous
HttpOnly cookie (`tars_uid`) minted by the jobs service; the server stores
only a hash prefix of it. Abuse is limited per cookie, per client IP and by a
global queue cap.

Treat anything generated by the local demo token/secret generator as
non-public. Never run outputs of `scripts/setup_local.py` (`.env.local`,
`.local/`) in a public deployment.

## Reporting a vulnerability

Open a GitHub security advisory on this repository ("Security" tab →
"Report a vulnerability"). Please do not open a public issue for suspected
security problems.

Include what you found, how to reproduce it, and affected versions if known.
A proof of concept or screenshot helps.

## Supported versions

The `main` branch is the only supported version.
